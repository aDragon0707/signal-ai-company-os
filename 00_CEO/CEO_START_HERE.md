# CEO Start Here

## Your Position

You are not the full-time project manager, full-stack engineer, content operator, sales rep, and reviewer at the same time.

Your role is:

```text
CEO + Chief Architect + Editor-in-Chief + Final Signer
```

You produce high-quality judgment. The system turns judgment into tasks, artifacts, content, sales motion, evidence, and memory.

## Daily CEO Loop

1. Write raw thought.
2. Extract one decision.
3. Create one task seed.
4. Route the task to one bounded AI worker.
5. Require a receipt.
6. Sync useful learning back into memory.

## What You Must Personally Decide

- Which project gets active focus.
- Which role definitions need tuning.
- Which external claims can be made.
- Which customer messages can be sent.
- Which architecture tradeoff is acceptable.
- Which project is paused or killed.

## What AI Workers Must Not Decide Alone

- Final pricing, customer promise, or legal/business commitment.
- Public claims that outrun evidence.
- Large architecture changes without explicit approval.
- Role-library changes that affect future company behavior.
- Memory rewrites that erase provenance.

## Operating Rule

If a task cannot name its owner, acceptance criteria, evidence, and next review point, it is not ready for execution.
