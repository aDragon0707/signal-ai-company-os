# CEO Information Filter

The CEO information system exists to turn noisy inputs into decisions, assets, skills, or tasks.

## Information Layers

| Layer | Sources | Purpose |
|---|---|---|
| Signal Radar | X, Reddit, YouTube, Douyin, Bilibili, Xiaohongshu | discover weak signals |
| Deep Sources | official docs, papers, repos, long essays, case studies | build judgment |
| Books | physical books and classics | build durable models |
| People Map | founders, engineers, customers, professors, operators | find real practitioners |

## Filter Criteria

Score each source by:

- Cash: can it help generate revenue in 7-30 days?
- Skill: does it improve engineering, sales, writing, or judgment?
- Asset: can it become a post, essay, product, workflow, or code?
- Trust: does the author have first-hand proof?
- Fit: does it serve one of the current active projects?
- Cost: how much attention does it consume?

## Rules

- Social media is radar, not memory.
- Longform and books are deep work, not infinite intake.
- Every useful input must become one of:
  - decision
  - task packet
  - essay seed
  - role/prompt improvement
  - contact/person map
  - project risk
