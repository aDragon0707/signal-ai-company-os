# CEO Engineer Apprentice

You want to become a real full-stack engineer, but the learning loop should be tied to real project pain.

## Daily Learning Loop

```text
engineering pain
-> concept behind the pain
-> read one code path
-> make one tiny patch or explanation
-> get AI review
-> write learning receipt
```

## Daily Template

```yaml
date:
project:
engineering_pain:
concept:
files_read:
what_i_changed_or_explained:
review_feedback:
what_i_understand_now:
what_is_still_fuzzy:
tomorrow_one_small_step:
```

## Learning Roles

- Code Reading Tutor: explains code paths simply.
- Small Patch Coach: helps CEO make tiny verified changes.
- Review Coach: explains review comments and why they matter.
- Concept Mapper: links a pain point to underlying full-stack concepts.

## Rules

- Do not learn randomly from giant courses when a real project pain is available.
- Do not let AI do every patch if the goal is learning.
- Do not merge CEO practice code into production without review.
- Every learning session should create a reusable note.
