# CEO 全栈工程师学徒系统

你想成为真正的全栈工程师，但学习循环应该绑定真实项目痛点。

## 每日学习闭环

```text
工程痛点
-> 背后的技术概念
-> 读一个代码路径
-> 做一个小 patch 或解释
-> 获得 AI review
-> 写 learning receipt
```

## 每日模板

```yaml
date:
project:
engineering_pain:
concept:
files_read:
what_i_changed_or_explained:
review_feedback:
what_i_understand_now:
what_is_still_fuzzy:
tomorrow_one_small_step:
```

## 学习角色

- Code Reading Tutor：简单解释代码路径。
- Small Patch Coach：帮助 CEO 做小而可验证的改动。
- Review Coach：解释 review comments 为什么重要。
- Concept Mapper：把工程痛点连接到底层全栈概念。

## 规则

- 有真实工程痛点时，不要随机刷大课。
- 如果目标是学习，不要让 AI 做掉所有 patch。
- CEO 练习代码不能未经 review 混进生产系统。
- 每次学习都要沉淀一条可复用笔记。
